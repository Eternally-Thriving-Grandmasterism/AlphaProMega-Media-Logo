# AlphaProMega Media Inc. — Color System

Locked palette for the Eternal Alpha Signal logo.

## Primary Colors

### Cosmic Navy
- **Hex:** `#0A1228`
- **RGB:** `10, 18, 40`
- **Alpha (opaque):** `FF`
- **Usage:** Primary background, dark mode base

### Cosmic Navy Soft (overlay)
- **Hex:** `#0A1228`
- **RGB:** `10, 18, 40`
- **Alpha:** `CC` (~80%) or `B3` (~70%)
- **Usage:** Cards, overlays, semi-transparent panels

### Metallic Gold
- **Hex:** `#D4AF37`
- **RGB:** `212, 175, 55`
- **Alpha:** `FF`
- **Usage:** Symbol, key accents, rays

### Soft Gold
- **Hex:** `#E8C872`
- **RGB:** `232, 200, 114`
- **Alpha:** `FF`
- **Usage:** Secondary text, highlights, "Media" word

### Pure White
- **Hex:** `#FFFFFF`
- **RGB:** `255, 255, 255`
- **Alpha:** `FF`
- **Usage:** Primary wordmark ("AlphaProMega")

### White Soft
- **Hex:** `#FFFFFF`
- **RGB:** `255, 255, 255`
- **Alpha:** `E6` (~90%)
- **Usage:** Secondary text when needed

## Transparency Reference

| Alpha Hex | Approx. Opacity | Use Case                  |
|-----------|-----------------|---------------------------|
| `FF`      | 100%            | Solid elements            |
| `E6`      | 90%             | Soft text                 |
| `CC`      | 80%             | Overlays                  |
| `B3`      | 70%             | Subtle gold overlays      |
| `80`      | 50%             | Heavy transparency        |
| `00`      | 0%              | Fully transparent         |

## Export Notes

- Prefer SVG for scalability.
- PNG exports available with navy background and transparent versions of the gold symbol.
- When placing on light backgrounds, use the gold symbol with sufficient contrast or add a subtle navy outline if needed.
